# Recoverix 백업/복원 및 파티션 작업 동의 문구 초안

제품명: Recoverix
버전: T.1.0.0

이 문서는 설치 중 고객에게 표시할 핵심 동의 문구 초안입니다.

## 설치 전 필수 안내

Recoverix 설치는 Windows 시스템 디스크의 파티션 구조와 부팅 구성을
변경할 수 있습니다.

설치 과정에서 다음 작업이 수행될 수 있습니다.

- 복구 런타임 파티션 생성
- 백업 이미지 저장 파티션 생성
- Windows 파티션 뒤에 미할당 공간 예약
- EFI 시스템 파티션에 Recoverix 부팅 파일 추가
- UEFI NVRAM 부팅 항목 등록 또는 수정
- Windows Agent 및 작업 스케줄러 등록
- 일반 사용자 삭제 방지를 위한 권한 설정

## 데이터 손실 경고

복원 기능을 실행하면 Windows 시스템 파티션이 백업 시점으로 되돌아갑니다.
복원 후 현재 Windows 파티션의 파일, 프로그램, 설정, 사용자 데이터가
삭제될 수 있습니다.

중요 데이터는 반드시 복원 전에 별도 저장장치에 백업해야 합니다.

## 디스크 복사 및 파티션 변경 경고

사용자가 디스크를 복사하거나, 파티션 크기 또는 순서를 변경하거나, EFI
파티션 또는 Recoverix 파티션을 삭제하면 백업 또는 복원이 정상 작동하지
않을 수 있습니다.

저장장치 교체, 하드카피, 파티션 축소/확장, 타사 파티션 도구 사용 후에는
Recoverix 부팅 항목, 백업 이미지, 복원 가능 상태를 다시 확인해야 합니다.

## Smart App Control 제한 고지

본 버전은 공인 코드서명 인증서가 적용되지 않을 수 있습니다. 이 경우
Windows Smart App Control, SmartScreen 또는 조직 보안 정책에 의해
설치파일 또는 일부 구성요소 실행이 차단될 수 있습니다.

## 설치 동의 체크박스 권장 문구

```text
[ ] Recoverix 설치가 파티션 구조, EFI 부팅 파일, UEFI NVRAM 부팅 항목,
    Windows Agent 및 작업 스케줄러를 변경할 수 있음을 이해했습니다.

[ ] 복원 실행 시 Windows 파티션의 현재 데이터가 삭제될 수 있으며,
    중요 데이터는 사용자가 별도로 백업해야 함을 이해했습니다.

[ ] 디스크 복사, 파티션 변경, EFI/Recoverix 파티션 삭제, 저장장치 교체
    후에는 백업 또는 복원이 제한될 수 있음을 이해했습니다.

[ ] 공인 코드서명 인증서가 적용되지 않은 버전은 Windows Smart App Control,
    SmartScreen 또는 조직 보안 정책에 의해 차단될 수 있음을 이해했습니다.

[ ] Recoverix 사용권 계약, 개인정보 및 로그 고지, 오픈소스 고지와 소스
    제공 안내를 확인했습니다.
```
