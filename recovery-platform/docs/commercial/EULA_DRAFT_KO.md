# Recoverix 사용권 계약서 초안

버전: T.1.0.0
제공자: FORYOUCOM
연락처: 1544-1879

본 문서는 Recoverix 설치파일에 포함할 고객용 사용권 계약서 초안입니다.
최종 배포 전 회사 정책 및 법무 검토를 거쳐야 합니다.

## 1. 제품 설명

Recoverix는 Windows 시스템 파티션의 백업 및 복원을 지원하는 복구
솔루션입니다. Recoverix는 별도의 복구 런타임, 복구 이미지 저장 공간,
EFI 부팅 구성, Windows Agent, 상태확인 및 안내 프로그램으로 구성될 수
있습니다.

## 2. 설치 동의

사용자가 Recoverix를 설치하면 다음 작업에 동의한 것으로 봅니다.

- Windows 시스템 디스크의 파티션 구조 확인
- 복구용 파티션 생성 또는 조정
- Windows 파티션 뒤의 미할당 공간 예약
- EFI 시스템 파티션에 Recoverix 부팅 파일 추가
- UEFI NVRAM 부팅 항목 등록 또는 복구
- Windows Agent 및 작업 스케줄러 등록
- Recoverix 상태확인 및 안내 프로그램 설치
- 설치 및 복구 관련 로그 생성

## 3. 데이터 손실 위험

Recoverix 복원 기능은 Windows 시스템 파티션을 백업 당시 상태로
되돌리는 기능입니다. 복원을 진행하면 현재 Windows 파티션의 파일,
프로그램, 설정, 사용자 데이터가 삭제되거나 변경될 수 있습니다.

중요 데이터는 Recoverix 사용 전에 별도 저장장치, 네트워크 저장소,
클라우드 또는 다른 안전한 위치에 백업해야 합니다.

Recoverix 설치, 백업, 복원, 파티션 변경, 디스크 복사, 사용자의 백업
미실시, 사용자의 복원 실행으로 발생하는 데이터 손실에 대하여 회사는
관련 법령상 허용되는 범위 내에서 책임을 부담하지 않습니다.

## 4. 지원하지 않는 상황

다음 상황에서는 Recoverix 백업 또는 복원이 실패하거나 제한될 수 있습니다.

- BitLocker가 활성화된 경우
- 동적 디스크, 비표준 파티션, 손상된 NTFS 상태
- Windows 빠른 시작, hibernation, dirty NTFS 상태
- 사용자가 파티션을 직접 수정한 경우
- 디스크 복사, 디스크 교체, 용량이 다른 저장장치로 이전한 경우
- EFI 파티션 또는 Recoverix 파티션을 삭제한 경우
- 저장장치 고장, 배드섹터, 컨트롤러 오류, 전원 차단
- Smart App Control, 보안 프로그램, 조직 보안 정책에 의해 구성요소가
  차단된 경우

## 5. Smart App Control 및 코드서명 제한

본 버전은 공인 코드서명 인증서가 적용되지 않을 수 있습니다. 이 경우
Windows Smart App Control, Microsoft Defender SmartScreen 또는 조직 보안
정책에 따라 설치파일, 실행파일, 스크립트 또는 일부 구성요소가 차단될 수
있습니다.

이 제한은 제품의 보안 정책상 고지되는 사항이며, 차단이 발생하면 Windows
보안 설정, 관리자 권한, 조직 보안 정책 또는 고객지원 안내를 확인해야
합니다.

## 6. 상태확인 및 안내 프로그램

Recoverix 상태확인 및 안내 프로그램은 PC 정보, 디스크/파티션 정보,
복구솔루션 사용 방법, 저장장치 용량 차이, 주의사항을 안내합니다.

표시되는 정보는 Windows 및 장치가 제공하는 값을 기준으로 하며, 제조사별
표기 방식, Windows 표시 방식, 드라이버, 장치 펌웨어, 파티션 상태에 따라
오차가 있을 수 있습니다.

## 7. 오픈소스 소프트웨어

Recoverix는 오픈소스 소프트웨어를 포함할 수 있습니다. 포함된 오픈소스
소프트웨어의 저작권, 라이선스, 고지사항은 `ThirdPartyNotices.txt`에
기재됩니다. 해당 라이선스에서 소스 제공을 요구하는 경우 `SourceOffer.txt`
에 따라 소스 제공 요청을 할 수 있습니다.

## 8. 상표

Recoverix는 FORYOUCOM의 제품명입니다. Recoverix는 Canonical 또는 Ubuntu의
공식 제품이 아니며, Canonical 또는 Ubuntu가 보증하거나 인증한 제품으로
표시되어서는 안 됩니다.

## 9. 삭제

Recoverix는 Windows 프로그램, 작업 스케줄러, EFI 파일, NVRAM 부팅 항목,
복구 파티션, 로그 및 상태 파일을 사용할 수 있습니다. 단순히 실행파일만
삭제하면 제품이 완전히 제거되지 않을 수 있습니다.

완전 제거는 Recoverix 제거 프로그램 또는 고객지원 안내에 따라 진행해야
합니다.
