# 알려진 제한 사항 (Known Limitations)

이 목록은 **현재 Recoverix 레퍼런스 구현**과 문서화된 테스트 범위를 기준으로 합니다. 항목은 배포판·플랫폼에 따라 달라질 수 있습니다.

| 영역 | 제한 내용 |
|------|-----------|
| Secure Boot | **서명 파이프라인·자동 재서명 불완전** 가능성; 테스트 시 **Secure Boot OFF 권장** |
| OEM 펌웨어 | **전 OEM 펌웨어 미검증** — Boot 변수·항목 문자열 차이 존재 |
| Fast Boot | 키보드 진입까지 **타이밍 문제** 발생 가능 |
| USB 키보드 | 초기 단계 **인식 타이밍** 이슈 보고 가능 |
| Multi-disk | **다중 디스크·다중 고정 디바이스** 구성 미지원(단일 디스크·단일 OS 가정) |
| RAID | **하드웨어/소프트웨어 RAID 미지원** |
| BitLocker | **암호화된 볼륨**과의 공존 미지원(테스트 및 정상 경로에서는 **OFF** 전제) |
| Legacy BIOS | **UEFI 전제** · Legacy 미지원 |
| Multi-boot | **다중 OS 동시 부팅**(듀얼 부트)·기타 브래드보드 브링업 시나리오 **미지원** |

추가로:

- **`firmware_reader`는 실제 분석 시 Windows 호스트**(비 dry-run 및 `bcdedit`)에 의존하는 구간이 있어, Recovery Linux 환경에서의 펌웨어 엔트리 **live 조회에는 한계**가 있을 수 있습니다. 이 경우 게이트·문서에는 **별도 확인 절차**를 두어야 합니다.

제한을 건드리는 환경에서는 **destructive 테스트 금지** 또는 **문서화된 예외 승인** 후에만 진행합니다.
